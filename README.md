# Project S+ Web App

Official web application for Project S+.

## Tech Stack

- React 19
- TanStack Start
- Supabase
- Tailwind CSS
- Cloudflare
- Vite

## Features

- Tournament registration
- MLBB and Tekken 8 registration flows
- Supabase authentication
- Public approved-entry listing
- Admin registration management
- Responsive tournament website
